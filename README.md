# EVE Echoes — Поиск планетарных ресурсов

Одностраничное приложение для поиска планетарных ресурсов и расстояний в прыжках.
Вся база (5 431 система, 38 298 планет, 147 936 записей о добыче) и требования
314 чертежей встроены в `index.html`.
После первой загрузки интернет не нужен.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Приложение вместе с базой. Имя менять нельзя — GitHub Pages ищет именно `index.html` |
| `sw.js` | Офлайн-режим: сначала сеть, при её отсутствии — кэш |
| `manifest.webmanifest` | Название и иконки для ярлыка на экране «Домой» |
| `icon-192.png`, `icon-512.png`, `icon-512-maskable.png` | Иконки приложения |
| `apple-touch-icon.png` | Иконка ярлыка на iPhone |
| `.nojekyll` | Отключает обработку Jekyll — GitHub отдаёт файлы как есть |

## Значения по умолчанию

Домашняя система — **U-HYZN**, максимум прыжков — **6**.
Кнопка «Сбросить» возвращает именно к ним.

## Как запоминаются фильтры

Текущий набор фильтров сохраняется сам, в двух местах сразу:

1. **В памяти браузера** — приложение открывается с последними настройками.
2. **В адресе страницы** (часть после `#`) — поэтому настройки переживают очистку данных Safari.
   Достаточно добавить страницу в закладки в нужном виде.

Отдельно можно сохранять именованные наборы — блок «Сохранённые наборы фильтров» вверху панели.

Важно: Safari и ярлык на экране «Домой» используют **раздельные хранилища**.
Наборы, сохранённые в Safari, не появятся в приложении с ярлыка, и наоборот.
Пользуйтесь чем-то одним.

## Вкладка «Ресурсы для проекта»

Показывает, где выгоднее добывать планетарные ресурсы под конкретную постройку.

- Три связанных уровня: категория → подкатегория → предмет.
  Корабли (202), Модули (46), Дроны (44), Сооружения (22).
- Поиск предмета по названию — ищет по всем категориям сразу;
  категория и подкатегория подставляются автоматически.
- Количество к постройке пересчитывает потребность и число заданий.
- Район поиска: домашняя система, максимум прыжков, регион, созвездие, система.
  По умолчанию — **U-HYZN** и **6 прыжков**.
- Результат по умолчанию — ровно 5 планет: лучшая по выработке под каждый
  из пяти нужных ресурсов. Переключатель «Планет на ресурс» расширяет выдачу до 3/5/10.
- Второй вид, «По планетам», показывает планеты, закрывающие сразу несколько ресурсов.
- Отдельно выбирать ресурс не нужно — он берётся из чертежа.
- Экспорт CSV по кнопке.

Полоса «Покрытие ресурсов» показывает, сколько из пяти нужных ресурсов вообще
встречается в заданном районе.

### Откуда данные по чертежам

NetEase не публикует официальный экспорт данных EVE Echoes — в отличие от EVE Online,
где CCP выкладывает SDE. Использован открытый набор сообщества (313 предметов
в 9 категориях), происходящий из той же таблицы, что и планетарная база сервиса,
поэтому названия ресурсов совпадают полностью.

Набор не покрывает риги — им планетарные ресурсы не нужны — и не содержит части предметов,
добавленных в игру после его составления (например, Cobra и Marshal в нём нет).

Недостающие предметы дописываются вручную в `extras.json` и попадают в сборку
через `build_bp.py`. У таких позиций в сводке стоит пометка «данные сняты из игры» —
они точнее табличных, потому что взяты прямо из окна чертежа.
Сейчас так добавлен **Orca** (Корабли → Промышленные).
Вариантов T2 у добывающих кораблей тоже нет: есть Covetor, но не Covetor II.
На выбор планет это не влияет — набор из пяти ресурсов у T1 и T2 одинаков,
отличаются только количества (у Covetor II они ровно в 1,39 раза больше). Сверяйте требования с окном производства
в игре перед крупной закупкой.

## Вкладка «Полимерные материалы»

Считает суммарное сырьё на заданное количество полимерных (средних) материалов:
Гексит, Фуллериды, Фенольные композиты, Силрамические волокна и остальные.

- Количество указывается отдельно для каждого материала.
- Эффективность производства — от 150% (без навыков) до 90% (максимум прокачки),
  по умолчанию 96%. Чем меньше процент, тем меньше сырья.
- Рядом с количеством показано, сколько чертежей нужно купить: один чертёж
  даёт 200 единиц, поэтому 201 шт. — это уже два чертежа.
- Кнопка «Очистить» в шапке списка обнуляет все количества разом; в скобках
  показано, сколько материалов сейчас выбрано. Рецепты при этом не трогаются.
- В блоке итогов — общее число чертежей и их суммарная стоимость в ISK.
  Цена каждого чертежа задаётся в его редакторе.
- Кнопка «Сохранить .txt» выгружает готовый список: что производим,
  сколько чертежей купить, во сколько они обойдутся и сколько сырья нужно.
- Внизу — суммарный список, разбитый на «Минералы (руда)», «Планетарные ресурсы»,
  «Газ (фуллериты)», «Лунная руда», «Звёздные кристаллы» и «Прочее сырьё».
  Экспорт CSV по кнопке.

### Рецепты

Все 12 рецептов встроены в приложение — загружать ничего не нужно.
Они сняты из окна чертежей в игре при эффективности материалов 96%,
выход — 200 единиц за задание.

Эти материалы добавлены в EVE Echoes патчем от 28.08.2024 и делаются из руды,
газа (фуллериты), лунной руды и звёздных кристаллов. Ни в наборе чертежей
сообщества, ни в других открытых источниках их состава нет — поэтому данные
взяты прямо из игры и при обновлениях игры могут разойтись.

Любой рецепт можно поправить или дополнить.
Кнопка «✎» рядом с материалом открывает редактор: название, выход за задание,
эффективность, при которой снят скриншот, и строки «ингредиент — количество».
Вводите ровно то, что показывает окно чертежа, включая блок «Требования к руде».

Пересчёт на другую эффективность делается пропорцией: рецепт, снятый при 150%,
при 96% даст 0,64 от введённых количеств. Поэтому неважно, при какой прокачке
сделан скриншот, — главное указать её в поле.

Рецепты хранятся в браузере. Кнопка «Рецепты» открывает выгрузку и загрузку
файла JSON — для переноса на другое устройство или резервной копии.
Там же «Добавить материал», если в игре появится новый.


## Публикация на GitHub Pages

1. Создайте репозиторий: **New repository** → имя, например `eve-pi`, видимость **Public** → **Create repository**.
2. **Add file → Upload files**, перетащите все файлы из этой папки → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт открыт по адресу `https://ВАШ_ЛОГИН.github.io/eve-pi/`.

## Открытие на iPhone

Откройте адрес в Safari → кнопка «Поделиться» → **На экран «Домой»**.
Приложение запустится без адресной строки и будет работать без интернета.

## Обновление

### С компьютера

1. Откройте репозиторий на github.com.
2. **Add file → Upload files**.
3. Перетащите новый `index.html`. Имя должно совпадать со старым — GitHub заменит файл, а не создаст второй.
4. Внизу **Commit changes**.
5. Через 1–2 минуты новая версия на сайте. Ход публикации виден во вкладке **Actions**.

### С iPhone

1. Сохраните новый `index.html` в «Файлы».
2. В Safari откройте репозиторий на github.com и нажмите **Aa → Полная версия сайта** — без этого кнопки загрузки не будет.
3. **Add file → Upload files → Choose your files** → «Обзор» → выберите файл из «Файлов».
4. **Commit changes**.

### Замена одного файла через веб-редактор

Если правка мелкая, можно не загружать файл заново: откройте нужный файл в репозитории,
нажмите на карандаш, отредактируйте, затем **Commit changes**.
Для `index.html` этот путь неудобен — файл на 2,7 МБ редактор открывает медленно.

### Если Safari показывает старую версию

Служебный воркер настроен «сначала сеть», поэтому обновление подхватывается само.
Если этого не произошло:

- потяните страницу вниз для перезагрузки;
- Настройки → Safari → **Очистить историю и данные**;
- либо удалите ярлык с экрана «Домой» и добавьте заново.

Менять версию кэша в `sw.js` при обновлении `index.html` не нужно.
